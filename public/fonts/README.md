# Bundled reading fonts

Atkinson Hyperlegible and Source Serif 4, downloaded from the official Google Fonts CSS/font endpoints on 2026-09-18. The app bundles their Latin WOFF2 faces for consistent offline reading; system fallbacks cover other scripts.

- https://fonts.google.com/specimen/Atkinson+Hyperlegible
- https://fonts.google.com/specimen/Source+Serif+4
- License sources: https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible and https://github.com/google/fonts/tree/main/ofl/sourceserif4

Both SIL Open Font Licenses are included beside the fonts. Filenames include a SHA-256 content prefix. The two Source Serif files are variable normal/italic faces reused by the CSS weight declarations.
